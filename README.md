# Dutch (Nederlands) — a jobslop plugin

jobslop in Dutch: every screen, plus Dutch job titles when you search in the Netherlands and Belgium.

## What it adds

- **Language:** Nederlands — the whole screen, plus local job titles when searching in NL, BE

## Install

It comes with jobslop — switch it on in **Settings → Plugins**.

To get a newer version before jobslop's next release: **Settings → Plugins → Check for plugin updates**,
or paste `https://github.com/JobSlop/jobslop-plugin-lang-nl` into **Install from link**.

## Making changes

See the plugin guide, `docs/PLUGINS.md` in the [jobslop repository](https://github.com/JobSlop/jobslop).
Raise `version` in `plugin.json` and publish a GitHub release tagged `v<version>`.
